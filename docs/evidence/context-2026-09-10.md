Every row completed 16 tasks, 16,000 yields and 16,016 Resume calls on one carrier.
Each Resume round trip includes the task's execution and return to its carrier:
the 32,032 context transfers are not independently timed. The separate cancelled
task ran its finally cleanup exactly once, outside the measurement interval.
Local Windows x86 and WSL2 Linux x64 also passed full checks and clean packaging

passed the focused optimized Pascal tests locally.

These millisecond-long experiments describe the minimal demo only. They are not
controlled OS comparisons, tail-latency measurements or a guarantee that a service
will start every 1 ms. The independent periodic workload still records missed
cycles: this hosted idle run skipped 0/2,000 on Windows, 0/2,000 on Linux and
33/2,000 on macOS. Inspect intervals and skipped counts together.

The 16 measured tasks requested 256 KiB each (4 MiB total) before timing. This is
a stack request, not measured committed memory; guards and runtime overhead add
cost. Windows exposes rounded reservation estimates and Unix the usable mapping.
The tests do not certify overflow recovery, sustained leak freedom or arbitrary
blocking calls. See the [context contract](../context-contract.md) and the
[support matrix](../support-matrix.md) for compiler and suspension restrictions.
