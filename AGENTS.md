# Delphi Fiber Runtime

This is a Pascal runtime project, not the parent directory's TypeScript project.
Read `docs/project-skills.md`, the approved spec and the active milestone plan.
Source lives in `src/`, tests in `tests/`, demos in `demo/`, native code in
`native/`, automation in `scripts/`. Root metadata (README, LICENSE, build
manifests, this bootstrap) is permitted. Keep files below 500 lines.

Use portable Pascal interfaces and isolate OS/compiler differences. Do not
claim a compiler/OS/CPU combination works without its own execution evidence.
Timing reports are descriptive unless an explicit qualification profile passes.
Never accept timeout, unexpected crash or missing output as a negative-test pass.

Multiple agents may work on distinct responsibilities. Assign ownership, never
revert others' edits, and obtain independent review before publishing code.
Use test-first development for behavioral code. Commit only files owned by the
task; use conventional messages. Do not add automated co-author trailers.

The existing sibling libraries are references, not files to modify.
No credentials or personal conversation exports belong in this public repo.
Update the owning contract when behavior changes and preserve the linked evidence.
